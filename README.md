# Orca Russian

Русский языковой пакет для [Orca](https://github.com/stablyai/orca): весь раздел «Настройки» — меню, заголовки, описания, кнопки, статусы и сообщения.

## Установка

1. Orca → Settings → Plugins → включить **Plugin system**.
2. **Manage sources** → добавить источник: `https://github.com/diman0111/orca-russian.git` (ветка `main`).
3. На вкладке **All** найти **Русский** → **Install** → просмотреть и включить.
4. Settings → Appearance → Language → `ru-RU — diman0111.russian`.

## Обновление

**Refresh** → на карточке плагина **Check for update**.

## Что не переведено

- Предупреждения безопасности плагинов — Orca запрещает языковым пакетам их менять.
- Строки, которые код Orca склеивает с английским окончанием «s» (например, «2 servers»), и служебные поисковые заголовки настроек проекта — их перевод ломает поиск в Orca.
- Строки новых версий Orca показываются на английском до следующего обновления пакета.

`l10n/source-en.json` — английский оригинал каждой строки (для поиска устаревших переводов), `l10n/GLOSSARY.md` — глоссарий.
